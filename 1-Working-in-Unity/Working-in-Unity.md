## 1) Working in Unity

### Getting Around in Unity

**Problem** - You want to learn how to navigate the Unity editor and understand what each component does, how to use it, and how to customize it.

**Solution** - Unity's user interface is organized along windows of content. When you launch Unity and create a new project, you will be taken to the editor's main window.

#### Toolbar

The toolbar contains controls that affect Unity as a whole. It is always at the top of the editor window and cannot be moved
*Tools palette* - This palette controls the behavior of the transform controls that appear when an object is selected. The modes are *Hand tool* for clicking and dragging in the Scene view; *Move tool* for moving objects; *Rotate tool* for rotating objects; and *Scale tool* for scaling objects around their pivot point or center.
